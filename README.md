# Jesús Mendoza

**AI Integration Engineer** · MCP servers, AI agents & Python automation · Connecting AI with legacy systems

I connect AI, APIs and automation to the systems a company already runs, legacy included. I come from 15+ years in IT infrastructure and systems, so I know those systems from the inside.

## What I build

- **MCP servers**: read-only, audited, secrets kept away from the model.
- **AI agents**: Python + LLMs (Claude, swappable providers) running in daily production.
- **Python automation**: bots on ERPs, tax portals and documents, with tests and deterministic logic where numbers must be exact.
- **API integrations**: REST APIs and Microsoft Graph connecting the ERP, Microsoft 365 and the help desk.

## Open source

**[jde-readonly-mcp](https://github.com/jesusmendoza-dev/jde-readonly-mcp)**: a read-only MCP server for JD Edwards EnterpriseOne on Oracle, with a SQL guard, secret redaction and an audit log.
